# Project Configuration for LangChain Backend

This configuration optimizes Claude Code for Python/LangChain backend development.

## Model Configuration

```json
{
  "model": "claude-3-5-sonnet",
  "env": {
    "MAX_THINKING_TOKENS": "8000",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "50",
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-3-5-haiku"
  }
}
```

## Key Settings Explained

- **model**: Using Sonnet for most tasks (60% cheaper than Opus, suitable for 80%+ of work)
- **MAX_THINKING_TOKENS**: 8000 tokens for Python-specific reasoning
- **CLAUDE_AUTOCOMPACT_PCT_OVERRIDE**: Compact at 50% context + to 80% for longer sessions
- **CLAUDE_CODE_SUBAGENT_MODEL**: Use Haiku for fast subagent tasks

## Switch to Opus When

- Designing complex system architecture
- Debugging tricky concurrency issues
- Reviewing security-critical code
- Making strategic technology decisions

Use `/model opus` to switch per-message.

## Recommended Workflows

### Daily Development

```
/model sonnet                    # Default for most tasks
/plan "Add new feature"          # Decompose into steps
/tdd                            # Write tests first
/code-review                     # Review implementation
/verify                         # Run full verification loop
```

### When Stuck

```
/model opus                      # Switch to more powerful model
/architect                       # Analyze design issues
/security-scan                   # Check for vulnerabilities
/build-fix                       # Resolve environment issues
```

### Cost Control

```
/cost                            # Show current session cost
/compact                         # Compact context to save tokens
/clear                           # Start fresh context
```
